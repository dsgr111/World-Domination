# 🌍 Мировое Господство (World Domination Game)

Полнофункциональный UI/UX дизайн браузерной многопользовательской стратегической игры с элементами glassmorphism. Дизайн выполнен точно по предоставленным скриншотам.

## 🎮 Особенности

### Дизайн
- **Современный минималистичный стиль** с элементами glassmorphism
- **Темная цветовая палитра** точно по скриншотам
- **Плавные анимации** и переходы между состояниями
- **Модальные окна** с blur-эффектом фона
- **Адаптивный дизайн** для всех устройств

### Цветовая палитра (точно по проекту)
- Основной фон: `#0a1628 → #1a2332 → #0f1a2e` (градиент)
- Фон карточек: `#1e2a3a` (темный)
- Фон элементов: `#293749` (средний)
- Акцент: `#00bcd4` (cyan)
- Успех: `#10b981` (зеленый)
- Опасность: `#ef4444` (красный)
- Предупреждение: `#fbbf24` (желтый)

### Страницы

#### 1. **Главная** (`/`)
- Компактная карточка по центру
- Логотип 🌍 + название
- Две кнопки: Войти (cyan) и Регистрация (зеленая)

#### 2. **Регистрация** (`/register`)
- Выбор аватара из 8 иконок (👑 🏆 ⚔️ 🛡️ 🏰 🎯 ⭐ 🔱)
- Поля: Имя пользователя, Email, Пароль
- Кнопка "Зарегистрироваться"
- Ссылка на вход

#### 3. **Вход** (`/login`)
- Поля: Email, Пароль
- Ссылка "Забыли пароль?"
- Кнопка "Войти"
- Ссылка на регистрацию

#### 4. **Лобби** (`/lobby`)
**Левая панель:**
- Кнопки "Создать" и "Ты ID"
- Форма создания игры (появляется при клике на "Создать"):
  - Название
  - Количество игроков (по умолчанию 6)
  - Раунды
  - Пароль (необязательно)
- Список доступных игр с ID, статусом, количеством игроков
- При клике на игру с паролем - модальное окно с blur-фоном

**Правая панель (Чат):**
- Общий чат с сообщениями
- Поле ввода с кнопкой отправки

**Внутри лобби игры:**
- Название лобби + ID
- Список игроков с выбранными странами
- Сетка выбора страны (12 стран: RU, US, CN, GB, FR, DE, JP, IT, BR, IN, CA, AU)
- Кнопки "Начать игру" и "Выйти из лобби"

#### 5. **Игра** (`/game`)
**Шапка:**
- Название игры + номер раунда
- Фаза игры (ОБСУЖДЕНИЕ / ПРИНЯТИЕ РЕШЕНИЙ)
- Таймер с предупреждением
- Бюджет и ядерное оружие

**Левая панель - Моя страна:**
- Флаг и название
- Прогресс-бар уровня жизни
- Список городов:
  - Уровень, доход, щиты
  - Визуальные эффекты уничтожения
- Статус санкций

**Центральная панель:**
- **Фаза обсуждения**: Чат с игроками
- **Фаза решений**: Панель действий
  - 🏙️ Развитие городов
  - 🛡️ Защита городов (щиты)
  - 💣 Ядерное оружие
  - 📜 Санкции
  - ✅ Применить решения

**Правая панель - Другие страны:**
- Список стран-противников
- Статусы (активна/уничтожена)
- Кнопка статистики
- Кнопка завершения игры

#### 6. **Победа** (`/victory`)
- Анимация конфетти 🎉
- Трофей победителя 🏆
- Информация о победителе:
  - Флаг, страна, игрок
  - Очки и количество городов
- Итоговая таблица всех участников
- Места с медалями (🥇🥈🥉)
- Кнопки "Новая игра" и "Главное меню"

## 🛠️ Технологии

- **React 18.3** - UI библиотека
- **React Router 7** - навигация
- **Motion (Framer Motion)** - анимации
- **Tailwind CSS v4** - стилизация
- **TypeScript** - типизация

## 🎯 Особенности реализации

### Модальные окна
- Модальное окно ввода пароля при входе в защищенное лобби
- Blur-эффект фона при открытии модального окна
- Закрытие по клику вне окна или на кнопку ✕

### Анимации
- ✨ Fade in/out для смены фаз игры
- 🎯 Hover-эффекты на всех интерактивных элементах
- 💫 Scale анимация при выборе элементов
- 🎊 Эффект конфетти на странице победы
- ⏰ Пульсация таймера при малом времени
- 💥 Shake-анимация уничтоженных городов

### ID лобби
- Автоматическая генерация уникального ID при создании игры
- Отображение ID в списке игр
- Отображение ID в заголовке лобби

### Интерактивность
- Все формы полностью работают
- Выбор аватара с визуальной обратной связью
- Выбор страны с блокировкой занятых
- Отправка сообщений в чат
- Действия в игре (развитие, защита, оружие, санкции)
- Смена фаз игры каждые 2 минуты

## 🚀 Навигация

```
/ (Главная)
├── /register → Регистрация → /lobby
├── /login → Вход → /lobby
│
/lobby (Лобби)
├── Создать игру → Форма создания
├── Выбрать игру → Внутри лобби → /game
│
/game (Игра)
├── Фаза обсуждения ⇄ Фаза решений
└── Завершить игру → /victory
│
/victory (Победа)
├── Новая игра → /lobby
└── Главное меню → /
```

Готовый backend находится в `backend/` и включает:
- REST API для авторизации, профиля, друзей, лобби, игры и техподдержки
- Socket.IO для общего чата, личных сообщений и переговоров
